# Screenshots

Add PNG screenshots here using these file names. The main [README](../../README.md) refers to them.

| File | What to capture |
| --- | --- |
| `dashboard.png` | Home dashboard with the feature cards and header |
| `skin-analysis.png` | Skin analysis result showing confidence, urgency, and recommendations |
| `video-analysis.png` | Video upload and its analysis result |
| `medication-scanner.png` | Medication scan result |
| `infographic.png` | A generated health infographic on the medication page |
| `voice-logger.png` | Voice logger with a transcript and analysis |
| `chat.png` | Health chat conversation (ideally one that shows the emergency alert) |
| `health-records.png` | Health records list with filters |
| `accessibility-toolbar.png` | Accessibility toolbar open, ideally with high contrast or large text on |

Use sample data only. Do not include real personal health information.
